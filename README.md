One-line roast of an alarm clock ringing at 6 AM on a Saturday morning. The entry reframes the alarm as a tiny landlord evicting the sleeper from the only home they can afford — sleep itself:

> Saturday, 6 AM: my alarm clock is a tiny landlord evicting me from the only home I can afford — sleep.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`.
